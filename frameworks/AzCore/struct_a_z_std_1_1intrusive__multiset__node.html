Detailed Description

template<class T>
struct AZStd::intrusive_multiset_node< T >

This is the node you need to include in your objects, if you want to use it in intrusive multi set. You can do that either by inheriting it or add it as a public member. They way you include the node should be in using the appropriate hooks. Check the intrusive_multi_set AZStdExamples.
